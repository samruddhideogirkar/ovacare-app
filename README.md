OvaCare: PCOD Early Detection Web App

Welcome to OvaCare, a web application designed to help users assess their risk of PCOD (Polycystic Ovarian Disease) using symptom-based analysis. This README will guide you through the features, setup, and deployment of the project.

📋 Features

Symptom-Based Assessment: Users answer a series of questions about irregular periods, weight gain, acne, hair growth, and more.

Risk Visualization: An animated gauge displays Low, Medium, or High risk levels with percentage.

Personalized Tips: After evaluation, users receive tailored suggestions (✅ do's and 🚫 don'ts) based on their risk level.
